# Accea Agent — Tech Stack

**Frontend:** HTML, CSS, JavaScript (Vanilla), Chrome Manifest V3
**Scanning:** axe-core 4.x (WCAG 2.1 AA/AAA)
**AI/LLM:** On-device AI, Local LLM (configurable)
**Backend:** Node.js, Express.js
**Privacy:** PII Redaction (7 regex patterns)
**Infra:** Docker, docker-compose, GitHub Actions
**Storage:** chrome.storage.local
**Export:** JSON, CSV, HTML, PDF, Clipboard
